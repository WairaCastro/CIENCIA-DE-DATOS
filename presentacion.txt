La Ciencia de Datos es una disciplina que combina conocimientos de programación,matemáticas, estadística y análisis de información para obtener resultados útiles a La Ciencia de Datos es una disciplina que combina conocimientos de programación, matemáticas, estadística y análisis de información para obtener resultados útiles a partir de diferentes conjuntos de datos. Su objetivo principal es transformar los datos en información que permita comprender situaciones, identificar patrones y apoyar la toma de decisiones en distintos campos del conocimiento.
En esta materia se busca desarrollar habilidades relacionadas con el manejo, la organización, el procesamiento y el análisis de datos. También es importante aprender a utilizar herramientas tecnológicas que faciliten el desarrollo de proyectos, la documentación de los procesos y el trabajo organizado.
Este repositorio de GitHub ha sido creado como parte de las actividades académicas de la materia de Ciencia de Datos. Su propósito es almacenar, organizar, modificar y documentar archivos de texto relacionados con el aprendizaje y el desarrollo de las actividades propuestas durante el curso.
Además, el repositorio permite practicar el uso de Git y GitHub como herramientas para administrar archivos y controlar sus versiones. Mediante estas herramientas es posible llevar un registro de los cambios realizados, conocer la evolución de los documentos y mantener un historial organizado del trabajo.
Git es un sistema de control de versiones que permite registrar los cambios realizados en los archivos de un proyecto. Gracias a esta herramienta, es posible consultar versiones anteriores, identificar modificaciones y mantener un seguimiento de las actividades realizadas.
GitHub es una plataforma en línea que permite alojar repositorios Git, facilitando el almacenamiento de archivos y el acceso al historial de cambios desde internet. También ofrece herramientas para documentar proyectos y compartir el trabajo con otras personas cuando sea necesario.
El uso de Git y GitHub es importante en el área de Ciencia de Datos, ya que los proyectos suelen incluir documentos, códigos de programación, conjuntos de datos, resultados de análisis y otros recursos que requieren una organización adecuada.
Durante esta actividad se crearán y modificarán diferentes archivos de texto con extensión .txt. Cada documento tendrá un propósito específico y permitirá practicar las operaciones básicas del control de versiones.
Entre las actividades principales se encuentran la creación de archivos, la modificación de su contenido, la revisión del estado del repositorio, la preparación de cambios, la creación de confirmaciones o commits y la publicación de los cambios en GitHub.
También se redactarán mensajes de confirmación claros y descriptivos para identificar las acciones realizadas en cada modificación.
